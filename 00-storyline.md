# Agentic Engineering: Vom Prompt zum Engineering-System

## Kernbotschaft

Die Qualität AI-gestützter Softwareentwicklung steigt nicht allein mit besseren Modellen. Sie steigt vor allem dann, wenn Anforderungen, Entscheidungen, Kontext und Qualitätskontrollen explizit werden.

## Die Reifestufen

| Stufe | Leitfrage | Primäres Ergebnis |
|---|---|---|
| 1. One-shot / Vibe Coding | Kannst du mir das bauen? | Code |
| 2. Grilling / Clarification | Was genau soll gebaut werden? | Geklärte Anforderungen |
| 3. Plan Mode | Wie sollten wir es bauen? | Technischer Plan |
| 4. Spec-Driven Development | Wie halten wir Intent und Entscheidungen dauerhaft fest? | Versionierbare Artefakte |
| 5. Agentic Engineering / Harness | Wie wird die Ausführung zuverlässig und überprüfbar? | Regeln, Tests, Evals, Tools |
| 6. Agentic Team | Wie verteilen wir Verantwortung und Arbeit? | Spezialisierte Rollen und Orchestrierung |

## Entwicklung in einem Satz

**Prompt → Fragen → Plan → Projektwissen → Governance → Organisation**

## Aussage für den Vortrag

> Vibe Coding optimiert die Code-Erzeugung. Agentic Engineering optimiert das System, das Code erzeugt.

## Sprecherhinweis

Die Stufen sind keine zwingende Prozessvorschrift. Sie sind ein Reifegradmodell. Kleine, reversible Aufgaben können bewusst auf einer frühen Stufe bleiben. Je größer Risiko, Lebensdauer und Teamkontext werden, desto wertvoller werden die späteren Stufen.
