# Vom Vibe Coding zum Agentic Engineering

## Der Reifegrad im Überblick

| Vibe Coding | Agentic Engineering |
|---|---|
| Prompt | Strukturierter Kontext |
| Conversation | Artefakte |
| Implizite Annahmen | Explizite Entscheidungen |
| Generation | Verifikation |
| Session State | Repository State |
| Ein Generalist | Spezialisierte Rollen, wenn sinnvoll |
| "Looks right" | Tests, Evals und Quality Gates |
| Modell als Tool | Engineering-System aus Modell, Prozess und Feedback |

## Was mit jeder Stufe zunimmt

```text
Expliziter Intent
        ↑
Persistenter Kontext
        ↑
Verifikation
        ↑
Governance
        ↑
Delegierbarkeit
```

## Was ebenfalls zunimmt

```text
Prozesskosten
Koordination
Pflege der Artefakte
Tooling-Aufwand
```

## Deshalb ist die richtige Frage nicht

> Welche Stufe ist die beste?

## Sondern

> Welche Stufe ist für Risiko, Lebensdauer und Komplexität dieser Aufgabe angemessen?

## Schlussbotschaft

**Vibe Coding ist ein hervorragender Startpunkt für Exploration.**  
**Agentic Engineering wird relevant, wenn Software reproduzierbar, wartbar und überprüfbar entstehen soll.**

Der Wettbewerbsvorteil liegt dann nicht nur im stärksten Modell, sondern im besseren System aus Intent, Kontext, Regeln und Feedback.
